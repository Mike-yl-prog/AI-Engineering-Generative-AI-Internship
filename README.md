# AI Guest Support Assistant - ABC Hotels & Resorts

## Week 1 AI Engineering & Generative AI Internship Assignment

**Prepared by:** Ademigoke Michael

## Project Overview

This project focuses on designing an AI-powered Guest Support Assistant for ABC Hotels & Resorts.

The goal is to create a Generative AI solution that improves guest experience by handling common enquiries, supporting booking processes, and providing fast, reliable assistance while maintaining human oversight.

## Solution Approach

The proposed solution uses Retrieval-Augmented Generation (RAG) to ensure responses are based on approved hotel information rather than unsupported AI-generated answers.
